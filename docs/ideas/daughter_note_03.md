# 서진이 아이디어 노트 3 (2026-09-27)

![노트](daughter_note_03.jpg)

세상 곳곳의 **수상한 물건 3가지**와 마지막 한마디.

| 칸 | 글씨 (읽은 그대로) | 해석 |
|---|---|---|
| **구멍** | "사탕이 있을까요? / 악당(?)이 있을까요?" + 까맣게 칠한 구멍 | 들여다보거나 들어가 보는 구멍. 사탕(보물)이 나올 수도, 나쁜 게 나올 수도 있는 운 요소 |
| **편지** | "3스테이지에서 나오는 마법사" + 리본 묶인 두루마리 | 3스테이지(챕터 3)에 나오는 **마법사**와 관련된 편지 |
| **상자** | "어두운 기운이 펄펄~ 뭐가 있죠?" + 보라·파란 기운이 감도는 상자 | 어두운 기운이 나오는 수상한 상자. 안에 뭐가 있는지는 비밀 |
| 아래 | "한 개라도!..." + 손(장갑?) 그림과 새싹 | ? — 물어보기 |

## 서진이 답 (2026-09-27)
1. 구멍 두 번째 줄은 "**이단**이 있을까요?" — 이단 = 이름이 아니라 **2단(두 번째 단계의 센 괴물)**. 구멍에는 사탕이 있을 수도, 2단 괴물이 있을 수도!
2. 편지 = **퀘스트 아이템**. 편지를 읽으면 **퀘스트가 시작**되고, 안에 **3스테이지 마법사가 전하는 말**이 들어 있음
3. 어두운 상자 = **아직 미스테리**
4. "한 개라도!..." = **이 중 한 개라도 게임에 만들어 달라는 간절한 소망**. 손 그림은 의미 없음
