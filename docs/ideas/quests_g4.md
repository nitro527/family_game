# G-4 맵마다 퀘스트 + 숨겨진 이벤트 (설계, 2026-10-06)

사용자 ⭐: "스토리가 너무 단순 — 맵마다 퀘스트를 강화해서 자연스럽게 연결, 숨겨진 이벤트로 특별 아이템".
아래 내용(누가·무엇·보상 이름)은 모두 ✏️ 임시 — 서진이에게 🙋.

## 구조 (코드)
- `Resources/Data/quests.json` 한 파일에 퀘스트·비밀 이벤트를 데이터로.
- 진행 상태는 세이브의 `Opened` (문자열 모음)에 `q_<id>` (받음) · `q_<id>_<n>` (n번째 찾음) · `q_<id>_done` (끝) 으로 → 세이브 버전 그대로.
- **찾기 퀘스트**: 마을 사람에게 말 걸면 부탁(받음) → 맵의 정해진 칸에 반짝이는 표시가 생김 → 밟으면 "찾았다! (2/3)" → 다 모아 가져가면 보상(특별 장비) + 다음 이야기로 이어지는 한마디.
- **숨겨진 이벤트**: 표시 없는 특정 물건(나무·바위·책장·눈사람 등)에 부딪혀 조사 → 한 번만 특별 아이템. 마을 사람 소문으로 힌트.
- 보상 아이템은 `Shops: "treasure"` (가게에 없음), 도감처럼 "특별 아이템" 표시.

## 챕터별 ✏️
| 챕터 | 부탁 (주는 사람 → 찾을 것 ×3 → 보상) | 숨겨진 이벤트 (힌트 → 보상) | 다음 이야기로 |
|---|---|---|---|
| 1 초원 | 별빛 마을 꼬마 젤리 → 밤하늘에서 떨어진 별 조각 → 별똥별 브로치 | 마을 아이 "초원 구석 나무에 구멍이 있대" → 네잎클로버 | "별 조각이 킹 젤리 성 쪽에서 떨어졌어" |
| 2 동굴 | 동굴 가게 젤리 → 반딧불 수정 → 수정 귀걸이 | 지하 샘 깊은 곳 → 동굴 진주 | "수정이 기지 쪽으로 이어져 있어" |
| 3 사막 | 오아시스 마을 → 낙타 방울 → 사막 장미 목걸이 | 꽃 핀 선인장 하나 → 선인장 꽃 | 편지 퀘스트와 연결 |
| 4 용암 | 온천 마을 대장장이 → 식은 용암석 → 불꽃 팔찌 | 온천 바닥 → 따끈따끈 조약돌 | "화산 젤리 대장이 낮잠을 깼대" |
| 5 눈 | 눈꽃 마을 아이 → 눈사람 단추 → 눈꽃 장갑 | 눈사람에게 말 걸기 → 당근 코 부적 | "예티가 눈 산에서 운대" |
| 6 도서관 | 사서 젤리 → 흩어진 그림책 → 마법 책갈피 | 오래된 책장 하나 → 비밀 일기장 (후반 떡밥은 🙋) | "엄마는 위쪽 마법진에" |
| 7 숲 | 도토리 젤리 → 숨은 도토리 → 요정 날개 | 큰 고목 (대장을 이긴 뒤) → 황금 도토리 | "정령 친구들 이야기" |

## 보상과 기믹 연결 (2026-10-06)
특별 장신구 몇 개는 끼고 있으면 **가족 모두** 그 상태 이상에 안 걸린다 (`items.json Resist`, `Equipment.ResistItem`):
동굴 진주 = 독 (동굴 거미), 불꽃 팔찌 = 화상 (용암 땅), 따끈따끈 조약돌 = 얼음 (다음 챕터 눈 덮인 곳에서 쓸모), 요정 날개 = 독·화상·얼음.
네잎클로버 = 가족 모두 조금 더 잘 피함(+6%), 황금 도토리 = 전투 골드 +25% (`items.json Perk`).

## 숨은 길 (2026-10-06, 맵 디자인)
겉보기엔 나무인데 지나갈 수 있는 칸 `'?'` 너머 숨은 빈터 → 숨겨진 이벤트(Secrets, Tile 'm'):
- 숲 왼쪽 위 나무 무리 → 요정 버섯 고리 → 요정 버섯 반지(독 막기). 힌트: 자연의 정령
- 눈 덮인 곳 왼쪽 전나무 무리 → 얼음 꽃 → 얼음 꽃 귀걸이(얼음 막기). 힌트: 스케이트 젤리
