# 딸의 아이디어 노트 1 (2026-09-27)

![노트](daughter_note_01.jpg)

딸(약 5세)이 직접 그린 게임 아이디어. **딸이 게임 기획자** — 여기 적힌 건 최대한 그대로 살린다.

## 읽은 내용
| 부분 | 그림·글씨 | 게임으로 옮기면 |
|---|---|---|
| 왼쪽 위 | 젤리 **1단 → 2단 → 3단(왕관)** | 젤리가 단계별로 커지고 세짐. 3단은 왕관 쓴 왕 젤리(= 지금의 킹 젤리) |
| 가운데 상자 | **파랑 = 쉬움, 초록 = 중간, 핑크 = 어려움** (1단에서 화살표) | 색깔이 곧 난이도. ⚠ 지금 게임은 분홍(HP12)이 초록(HP18)보다 약함 → 순서 바꾸기 |
| 가운데·오른쪽 | 깃발 꽂힌 성(시작점), 성 옆 어두운 구멍, 겹친 원: "쉬움·중간", "어려움", "2단" | 지역 난이도 지도: 성 가까이는 쉬움·중간, 멀어질수록 어려움, 먼 곳엔 2단 젤리 |
| 아래 왼쪽 | **동굴**: 돌 젤리, **광물** 젤리(세모 결정), **수정** 젤리(뾰족) | 동굴 몬스터 3종. 돌·수정은 있음 → **광물 젤리 추가** |
| 아래 가운데 | **사막**: 선인장, **카우보이 젤리**(모자), **선인장 젤리** | 새 지역 사막 |
| 아래 | **숲**: 나무, **나무 젤리**(나뭇가지), **벌레 젤리**(더듬이) | 새 지역 숲 |
| 아래 오른쪽 | **성**: 칼·창, **군인 젤리**(투구·삼지창) | 적의 성, 병사 젤리 (챕터 2 적 기지와 연결 가능) |

## 딸에게 확인한 것 (2026-09-27)
- 오른쪽 위 두 사람 = **우리 파티** → 챕터 3부터 딸 + 아들(용사) 2인 파티
- 성 옆 까만 점 = **문 손잡이** (성 문)
- 모자 젤리 = **카우보이 젤리** 맞음
