# 개선 백로그 — 자동 개선 작업이 위에서부터 하나씩 처리

규칙
- 한 번 실행할 때 **항목 1개**(작으면 2개)를 끝까지 처리해요: 구현 → 검증(SmokeTest + PlaytestProbe + 스크린샷 확인) → git 커밋 → 이 파일 갱신
- 🙋 표시는 **사용자 확인이나 계정이 필요한 항목**이에요. 자동 실행에서는 건너뛰고, "사용자 확인 필요"에 적어 둬요.
- 규칙: 배치 모드(자동 테스트)는 소리를 끈다 — `BatchModeMute.cs`, `BatchModeEditorMute.cs`. 사용자가 개발 중 소리를 싫어함. 테스트 중 exe를 직접 실행해 소리를 내는 일은 하지 않는다.
- 새로 발견한 문제나 아이디어는 알맞은 위치에 추가해요 (조사 결과는 docs/research_*.md).
- 설정(이름·세계·몬스터·이야기)의 기준은 **docs/lore/ 설정집**. 게임과 다르면 설정집을 따르고, 설정을 새로 지어내지 않아요 (빈 곳은 ✏️ 임시로 표시).
