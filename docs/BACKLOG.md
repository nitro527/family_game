## 진행 대기 (우선순위 순)
0. [ ] ⭐ **최우선 (사용자 지시) — 딸 캐릭터 에셋 A4 인쇄용 시트**
   - 원본: `assets/characters/gen/girl/` (투명 PNG, 표정 아이콘, 포즈, 카드, 초상화)
   - 출력: `assets/print/girl/` 에 **A4 세로, 300dpi (2480×3508px) PNG + 여러 장을 묶은 PDF 1개**
   - 시트 구성 (흰 배경, 가장자리 여백 10mm, 자르기 편한 연회색 점선 재단선):
     1) 표지: 메인 일러스트 크게 + "꼬마 마법사 첫째" 제목
     2) 표정 아이콘 6종: 원형이나 사각 스티커용 격자 (각 약 50mm)
     3) 포즈 모음: 전투 4종 + 걷기 6종 + 대화 초상화
     4) 카드 2장: 실제 카드 크기 63×88mm, 카드 목업 이미지
   - Python(PIL) 스크립트 `tools/print_sheets.py` 로 만들어서 다시 뽑을 수 있게. 결과 PNG를 직접 열어 정렬 상태 확인
   - 한글 글씨는 맑은 고딕(C:/Windows/Fonts/malgunbd.ttf)
1. [ ] **배경음악(BGM) — 코드로 칩튠 작곡**: 필드, 전투, 보스, 엔딩 4곡을 Sfx 처럼 코드로 합성해서 반복 재생. 음량 조절 포함
2. [ ] **데이터 주도 구조**: 적, 스킬, 대사를 C# 하드코딩에서 `Resources/Data/*.json` 으로 분리 (SmokeTest 로 로딩 검증)
3. [ ] **세이브/로드**: PlayerPrefs(JSON)로 위치·레벨·보스 격파 저장, 타이틀에 "이어하기" 버튼
4. [ ] **게임패드·터치 입력**: Keys 계층에 조이스틱과 화면 터치 버튼 추가 (태블릿에서 딸이 직접 플레이)
5. [ ] **필드 연출 다듬기**: 물결 애니메이션, 샘물 반짝임, 꽃 흔들림, 걸을 때 먼지, 전투 진입 소용돌이 전환
6. [ ] **전투 연출 다듬기**: 적 등장 연출, 적마다 다른 공격 모션, 레벨업 팡파르 이펙트, 피격 시 화면 빨간 번쩍임
7. [ ] **콘텐츠 확장**: 두 번째 지역(숲/동굴), 새 젤리 2종, 중간 보스, 상점(사탕 구매)
8. [ ] **밸런스 재점검**: 새 콘텐츠 추가 뒤 BalanceSimulation 기준 조정 (5살 아이도 깰 수 있게)
9. [ ] **접근성**: 글자 크기 옵션, 대사 자동 넘김 속도 옵션, 효과음·BGM 볼륨 옵션
10. [ ] **카드 게임 프로토타입**: 딸 카드 2장 목업(tools/card_mockup.py)을 바탕으로 Unity 1인 카드 배틀 프로토타입 (별도 씬)
