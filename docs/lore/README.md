# 세계관 설정집

**지금 Unity 게임(`unity/GirlAdventure`)은 테스트 버전이에요.** 설정을 계속 넓혀 가다가, 나중에 이 설정집을 바탕으로 제대로 된 게임을 새로 만들어요.
그래서 **이 설정집이 기준(정본)**이에요. 게임과 설정이 다르면 설정집이 맞고, 게임 쪽을 고쳐요.

## 누가 정하나
- **서진(딸, 7살)이 세계관의 주인**이에요. 서진이의 노트·말이 최우선이고, 어른은 빈 곳을 메우거나 정리만 해요.
- 새 노트 → `docs/ideas/daughter_note_NN.jpg/.md` 에 원본과 해석을 남기고 → 이 설정집에 반영해요.
- 서진이가 정한 것은 ⭐, 어른(아빠·Claude)이 임시로 채운 것은 ✏️ 로 표시해요. ✏️ 는 서진이가 바꾸면 바로 바뀌어요.

## 그림 에셋
- 가족: `assets/characters/gen/<girl|boy|mom|dad|family>/`, 요약 `assets/characters/overviews/`
- 몬스터·정령: `assets/monsters/` (도감)

## 고칠 때 규칙
- 설정이 바뀌면 해당 문서만 고치고, 맨 아래 "바뀐 기록"에 날짜와 한 줄을 남겨요.
- 이미 게임(테스트 버전)에 들어간 내용이 바뀌면 `docs/BACKLOG.md` 에 반영 항목을 추가해요.
