# 서진이에게 물어볼 것 · 아직 안 정해진 것

답을 받으면 해당 설정 문서에 ⭐ 로 옮기고 여기서 지워요.

## 원소·정령
- [ ] 원소 정령은 같이 싸우는 **동료**? 주문으로 불러내는 **소환수**? 아니면 서진·지훈이 쓰는 **마법 속성**?
- [ ] 원소끼리 이기고 지는 관계가 있을까? (예: 물 > 불)
- [ ] 보라 구슬은 어디서 왔을까? (서진이도 모름 — 나중에 떠오르면)
