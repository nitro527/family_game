## 4. 확장을 위해 도입을 검토한 방법

### A. 그림 파이프라인 — 로컬 이미지 생성 (추천: 한 번 실험)
- 이 PC에 **RTX 4070 SUPER (12GB)** 가 있어 로컬 생성이 가능 → **무료·무제한·완전 자동화**(루틴도 그림 가능), PC 잠금·클립보드 문제 없음
- 도구: ComfyUI(무료) + 참조 이미지 기반 모델. 12GB 에서 SDXL·Flux 양자화판이 적당. 여러 참조 그림을 섞는 FLUX.2 계열이 캐릭터 일관성에 강함
- **라이선스 주의**: Flux.1-schnell·FLUX.2 [klein] 4B 는 Apache 2.0(상업 가능), Flux.1-dev·FLUX.2-dev 는 비상업 → 나중에 공개할 생각이면 Apache 모델로
- 방법: 지금 확정 그림(4명 × 11종 + 도감 22종)을 참조·학습 자료로 → 우리 화풍 LoRA 또는 참조 워크플로
- 필요한 결정 🙋: 설치·모델 다운로드(수 GB) 승인. 품질이 Gemini 만큼 나오는지 1~2시간 실험 후 판단

### B. Unity 공식 Claude Code 플러그인 / MCP (추천)
- 2026-09 Unity 가 공식 Claude Code 플러그인(Unity 스킬 29개)과 MCP 서버를 냄 → 에디터를 켠 채로 씬 확인·콘솔 읽기·실행을 Claude 가 직접
- 지금은 배치 모드로만 확인해서 느리고(실행마다 수십 초) 화면을 스크린샷으로만 봄 → 개발 속도·확인 정확도가 올라감
- 필요한 결정 🙋: 플러그인 설치 승인 (백로그 🙋 에 이미 있음)

### C. 백업 — 비공개 원격 저장소 (강력 추천)
- 지금 모든 작업이 이 PC 한 곳에만 있음 (`.git` 142MB, `assets/` 172MB). 디스크가 고장 나면 전부 사라짐
- 비공개 GitHub 저장소 + Git LFS(그림 파일) 또는 외장 디스크·클라우드 드라이브에 정기 복사
- 필요한 결정 🙋: 지금 규칙은 "push 금지" → 원격을 둘지 사용자가 결정

### D. 설정 → 데이터 한 곳에서 (추천: 다음 회차들에 조금씩)
- 지금 몬스터 정보가 `docs/monsters/monsters.json`(도감)과 `enemies.json`(게임) 두 곳 → 이름·설명이 어긋날 수 있음
- 설정집·도감을 원본으로 두고 게임 데이터를 생성(또는 검사)하는 스크립트: 서진이 설정이 바뀌면 게임까지 자동 반영

### E. 본편(제대로 된 게임)으로 갈 때의 구조 (나중에)
- 지금 테스트 버전의 **Sim 규칙 코드와 JSON 데이터, 자동 테스트 방식은 그대로 가져갈 가치**가 있음
- 바꿀 것: 화면 코드를 씬·프리팹·ScriptableObject 로 나누기, 맵은 에디터 도구(Unity Tilemap 또는 Tiled/LDtk)로 그리기, 대사·퀘스트는 대화 스크립트(Yarn Spinner·Ink, 무료)로
- 시점: 챕터 3까지 테스트 버전으로 재미를 검증한 뒤 → 설정집이 챕터 5개 정도 쌓였을 때

### F. 서진이 참여 넓히기
- 몬스터·지역을 그릴 수 있는 **빈 양식 종이**(이름·사는 곳·세기·특기 칸)를 만들어 주면 해석이 정확해지고 서진이도 더 재미있어함
- 게임 속 "서진이가 만든 몬스터" 표시, 도감에 서진이 원래 스케치 보여 주기

### G. 카드 게임 (규칙 정하면)
- 카드 목업 8장(4명 × 일반·필살기)이 준비됨. 덱 크기·코스트·턴·승리 조건을 서진이와 정하면 별도 프로토타입

## 6. 작업 방식 — 지금 방식이 좋은가, 더 나은 방식은?

### 지금 방식 (이번 주말)
| 역할 | 방식 | 좋은 점 | 불편한 점 |
|---|---|---|---|
| 개발 | **이 PC의 예약 작업**(이어달리기, 한 번에 하나) | Unity·파일에 직접 접근, 자면서도 진행 | 루틴 세션을 휴대폰에서 보기 어려움, 대화 세션과 사용량을 나눠 씀 |
| 그림·설계 | **대화 세션** + Claude in Chrome 으로 Gemini 웹 조작 | 무료, 품질 좋음 | 사람이 PC 앞에 있어야 함(잠금 시 불가), 하루 약 40장, 조작이 자주 꼬임 |
| 확인 | Unity 배치 모드 테스트 + 스크린샷 | 자동으로 끝까지 검증 | 한 번에 수십 초~몇 분, 에디터 화면은 못 봄 |

결론: **개발은 "이 PC에서 도는 예약 작업"이 계속 맞아요.** 클라우드 루틴·클라우드 세션은 Unity 와 Gemini(브라우저)를 못 써서 이 프로젝트엔 안 맞아요. 대신 아래를 **더하면** 훨씬 편해져요.

| 2 | **Unity 공식 Claude Code 플러그인(MCP)** | Claude 가 켜진 Unity 에디터를 직접 조작·확인 → 개발·버그 확인이 빨라짐 | 플러그인 **설치 승인**, 작업할 때 Unity 에디터 **열어 두기** |
