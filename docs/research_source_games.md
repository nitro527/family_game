# 소스 공개 상용 게임 조사 — 우리 프로젝트에 쓸만한 것

출처: [Wikipedia — List of commercial video games with available source code](https://en.wikipedia.org/wiki/List_of_commercial_video_games_with_available_source_code) (2026-09-26 조회)
기준: 우리 프로젝트 = **Unity(C#) 2D, 드래곤 퀘스트 풍 턴제 RPG + 추후 카드 게임, 가족용 비상업**

## 먼저 알아둘 점
- 목록의 절반 이상은 **유출된 소스**예요 (Cyberpunk 2077, Gwent 카드게임, GTA V, 포켓몬 등 해킹이나 랜섬웨어로 유출).
  **법적으로 쓸 수 없고, 참고용으로 열어보는 것도 권하지 않아요.**
- 정식으로 공개된 최신작은 대부분 **FPS 엔진**(Ion Fury, Wrath, Skin Deep, Quadrilateral Cowboy)이라 우리와 장르가 달라요.
- **Unity 기반은 하나도 없어요.** 그래서 "가져다 쓰기"보다는 **구조와 설계를 참고하는 용도**예요.
- 라이선스 메모:
  - GPL: 우리 코드에 섞으면 배포할 때 우리 코드도 GPL로 공개해야 해요. 집에서만 쓰면 괜찮지만, 참고만 하는 게 깔끔해요.
  - CC BY-NC: 비상업이면 출처를 표시하고 재사용할 수 있어요.

## 우리 프로젝트에 적용할 제안
1. **데이터 주도 구조로 전환** (Wargroove, Pixel Dungeon 방식)
   - 지금은 적, 스킬, 대사가 C# 코드 안에 들어 있어요.
   - 이걸 JSON이나 ScriptableObject 데이터 파일로 빼면, 몬스터·스킬·카드를 코드 수정 없이 늘릴 수 있어요.
   - 카드 게임으로 확장할 때도 같은 데이터를 쓸 수 있어요.
2. **이벤트·대사 스크립트 시스템** (Barkley 2 방식)
   - 표지판, 샘물, 보스 등장 같은 이벤트를 코드 대신 간단한 스크립트 데이터로 정의해요.
   - 그러면 가족들이 대사를 직접 고칠 수 있어요.
3. **세이브/로드 + 장비·아이템** (Pixel Dungeon 참고): 게임을 더 길게 만들 때 필요한 다음 단계예요.
4. **카드 게임 쪽**: 목록에 합법적으로 공개된 카드 게임이 없어요 (Gwent는 유출이라 제외). 카드 게임은 별도 조사가 필요해요.
