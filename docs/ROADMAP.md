# 로드맵 — "꼬마 마법사 첫째의 모험" → 드래곤 퀘스트급으로

## 북극성 (최종 목표)
DQ 시리즈처럼 **"누구나 쉽게 시작하고, 끝까지 따뜻한 모험"**.
가족이 주인공이고, 7살 딸(주인공 서진)이 직접 끝까지 플레이할 수 있는 완성도 높은 2D JRPG.

> **지금 게임은 테스트 버전.** 세계관·설정의 기준은 [docs/lore/](lore/README.md) (설정집)이고, 설정을 넓힌 뒤 그걸 바탕으로 제대로 된 게임을 새로 만든다 (2026-09-27 사용자).

## 마일스톤
- **M1 기반 다지기** (완료): BGM, 데이터 주도 구조, 세이브, 터치 입력 → BACKLOG 1~4
- **M2 살아있는 세계** (현재, BACKLOG 37~41): 시작 마을(NPC, 대화 시스템, 상점, 여관), 보물상자, 골드, 장비
- **M3 전투의 깊이** (BACKLOG 42~46): 몬스터 그룹 전투, 주문 목록 메뉴, 상태이상, 몬스터 도감, 전투 이펙트 강화
- **M4 이야기**: 챕터 구조, 컷신 스크립트, 던전 1(동굴) + 중간 보스, 두 번째 필드
- **M5 가족 파티**: 동료 합류 시스템 (막내 용사 → 엄마 → 아빠), 파티 전투 UI
- **M6 완성도**: 옵션, 접근성, 밸런스, 엔딩 연출, 설치 파일, 태블릿 빌드

## 이야기 구성 (사용자 아이디어, 2026-09-26)
- **챕터 1 (완성)**: 별빛 마을 → 필드 → 킹 젤리 성 → 보스 격파 → 별빛 회복
- **챕터 2 — 동굴 (구현됨)**: 무대는 초원이 아니라 동굴. 딸 혼자 진행 (2026-09-27 사용자 결정)
  1. 필드 어딘가의 **보물상자**를 연다 → **열쇠** 획득
  2. 열쇠가 있어야 **적 기지** 문이 열린다 (없으면 "잠겨 있다" 대사)
  3. 기지 안에서 **챕터 2 보스**를 잡는다
  - 필요한 시스템: 챕터 진행 상태(세이브 포함), 보물상자·아이템(열쇠), 잠긴 문, 새 맵(기지)
- **챕터 2 끝 → 아들(용사) 합류, 챕터 3부터 2인 파티** (2026-09-27 사용자 결정. 딸 노트의 오른쪽 위 두 사람 = 우리 파티)
  - 챕터 2 보스 격파 후 합류 이벤트 → 필드 대열 걷기(딸 뒤를 따라옴) + 2인 파티 전투
  - 챕터 3 무대 후보: 딸 노트의 숲·사막·적의 성 (docs/ideas/daughter_note_01.md)
  - **챕터 3 = 동생을 동료로 얻고 사막 마을 모험** (2026-09-27 사용자 결정). 숲·적의 성은 그 뒤 챕터 후보
- **딸의 설정 (2026-09-27, docs/ideas/daughter_note_02.md)**: 불·물·바람·자연 **4원소 정령은 우리 편**. 검은 **정체불명** 2마리가 나타나는데, 그 정체는 **4원소가 합쳐진 것** → 후반 반전·비밀 보스 후보. 그보다 더 센 **보라 구슬**(정체 모름)이 최종 비밀 보스 후보. 이단 킹 젤리(킹 젤리보다 더 셈)도 후반 보스 후보
