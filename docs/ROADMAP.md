# 로드맵 — "꼬마 마법사 첫째의 모험" → 드래곤 퀘스트급으로

## 북극성 (최종 목표)
DQ 시리즈처럼 **"누구나 쉽게 시작하고, 끝까지 따뜻한 모험"**.
가족이 주인공이고, 5살 딸이 직접 끝까지 플레이할 수 있는 완성도 높은 2D JRPG.

## 마일스톤
- **M1 기반 다지기** (현재): BGM, 데이터 주도 구조, 세이브, 터치 입력 → BACKLOG 1~4
- **M2 살아있는 세계**: 시작 마을(NPC, 대화 시스템, 상점, 여관), 보물상자, 골드, 장비
- **M3 전투의 깊이**: 몬스터 그룹 전투, 주문 목록 메뉴, 상태이상, 몬스터 도감, 전투 이펙트 강화
- **M4 이야기**: 챕터 구조, 컷신 스크립트, 던전 1(동굴) + 중간 보스, 두 번째 필드
- **M5 가족 파티**: 동료 합류 시스템 (막내 용사 → 엄마 → 아빠), 파티 전투 UI
- **M6 완성도**: 옵션, 접근성, 밸런스, 엔딩 연출, 설치 파일, 태블릿 빌드

## 이야기 구성 (사용자 아이디어, 2026-09-26)
- **챕터 1 (완성)**: 별빛 마을 → 필드 → 킹 젤리 성 → 보스 격파 → 별빛 회복
- **챕터 2 — 동굴 (구현됨, 동료는 에셋 대기)**: 무대는 초원이 아니라 동굴. 동료가 합류한다 (캐릭터 에셋은 사용자가 만들어 줄 예정 🙋)
  1. 필드 어딘가의 **보물상자**를 연다 → **열쇠** 획득
  2. 열쇠가 있어야 **적 기지** 문이 열린다 (없으면 "잠겨 있다" 대사)
  3. 기지 안에서 **챕터 2 보스**를 잡는다
  - 필요한 시스템: 챕터 진행 상태(세이브 포함), 보물상자·아이템(열쇠), 잠긴 문, 새 맵(기지), 동료 파티 전투(M5 앞당김)
