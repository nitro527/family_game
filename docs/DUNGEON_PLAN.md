# 챕터 던전 계획 (2026-10-11)

사용자: "각 챕터 보스전은 바로 진행하지 말고 던전을 하나 만들어. 예를 들면 챕터 1은 성에 들어가면 성 안을 돌아다니다가 보스를 만나게.
그리고 보스 캐릭터도 필드 에셋을 만들어서 맵에서 보이게 해."

## 지금
- 바깥 맵의 보스 칸(챕터 1 성문 'G', 나머지 'B')을 밟으면 바로 만남 대사 → 보스전 (`GameRoot.BossRoutine`, chapters.json `BossMap`·`BossTile`).
- 보스는 맵에 보이지 않는다 (칸 글자뿐).

## 바꿀 흐름
1. 바깥 맵의 보스 칸 = **던전 입구**. 밟으면 화면이 어두워졌다가 던전 맵 입구로 (마을 드나들기와 같은 방식, `P.InDungeon`).
2. 던전 = 방 여러 개 + 복도 + 계단(맵 입체화 높이) + 몬스터(그 챕터의 강한 쪽) + 보물상자 + 샘물(쉼터) + 막다른 길. 입구 칸을 밟으면 다시 바깥으로.
3. 맨 안쪽 방에 **보스가 서 있다** (보스 그림을 줄인 필드 스프라이트, 숨 쉬듯 들썩·가까이 가면 "!"). 부딪히면 만남 대사 → (준비 레벨 확인) → 보스전.
4. 이기면 지금처럼 챕터 완료 → 다음 챕터 (던전 안에서 끝나도 됨).

## 던전 7곳 (✏️ 이름·구성은 임시, docs/lore/open_questions.md 🙋)
| 챕터 | 입구 | 던전 | 그림 |
|---|---|---|---|
| 1 | 초원 성문 | **킹 젤리의 성** — 성문 홀 → 복도 → 2층 계단 → 옥좌 방 | 회색 돌 성 |
| 2 | 동굴 기지 문 | **젤리 장군의 기지** — 막사·창고·철창 | 어두운 바위 |
| 3 | 남쪽 바위 골짜기 | **바위 골짜기 굴** | 사암 |
| 4 | 화산 동굴 입구 | **화산 속** — 용암 강·돌다리 | 현무암·용암 |
| 5 | 눈 산 동굴 입구 | **얼음 동굴** — 미끄러운 얼음 | 얼음 |
| 6 | 책 더미 옥좌 | **금지된 서고** | 나무 책장 |
| 7 | 고목 구멍 | **큰 고목 속** | 나무 뿌리 |

## 단계 (단계마다 스모크·프로브·빌드)
| 단계 | 할 일 |
|---|---|
| **D1. 틀** | MapKind 던전 7종 + mapkinds.json(노래·배경·몬스터 구역) + `ChapterDef.Dungeon` · `P.InDungeon`(세이브), 던전 맵 글자 표(`Resources/Data/dungeons.json` — 맵 그림을 글자 줄로), 드나들기(`DungeonRoutine`), 맵 그리기(동굴 그리기 + 테마 색), 보스 필드 스프라이트(`GameRoot.Bosses.cs`), 보스에 부딪히면 BossRoutine |
| **D2. 챕터 1 성** | 성 맵·몬스터·상자·계단, 프로브: 성문 → 성 안 → 옥좌 방 킹 젤리 → 보스전 |
| **D3. 챕터 2~7** | 맵 6장, 프로브의 보스 가는 길을 "입구 → 던전 → 보스 앞" 으로 |
| **D4. 다듬기** | 던전 전용 소품(촛대·깃발·창살), 보스 방 연출(문이 닫힘·보스가 돌아봄), 던전 지도 이름 띠 |

## 원칙
- 길 이어짐 스모크(HeightTests 와 같은 BFS)로 입구 → 보스 앞까지 길이 있는지 맵마다 확인.
- 기존 세이브: 보스 칸에 서 있던 세이브도 바깥 맵에서 시작하니 문제없음. `InDungeon` 은 없으면 false.
