# 챕터 던전 계획 (2026-10-11)

사용자: "각 챕터 보스전은 바로 진행하지 말고 던전을 하나 만들어. 예를 들면 챕터 1은 성에 들어가면 성 안을 돌아다니다가 보스를 만나게.
그리고 보스 캐릭터도 필드 에셋을 만들어서 맵에서 보이게 해."

## 지금
- 바깥 맵의 보스 칸(챕터 1 성문 'G', 나머지 'B')을 밟으면 바로 만남 대사 → 보스전 (`GameRoot.BossRoutine`, chapters.json `BossMap`·`BossTile`).
- 보스는 맵에 보이지 않는다 (칸 글자뿐).

## 바꿀 흐름
1. 바깥 맵의 보스 칸 = **던전 입구**. 밟으면 화면이 어두워졌다가 던전 맵 입구로 (마을 드나들기와 같은 방식, `P.InDungeon`).
2. 던전 = 방 여러 개 + 복도 + 계단(맵 입체화 높이) + 몬스터(그 챕터의 강한 쪽) + 보물상자 + 샘물(쉼터) + 막다른 길. 입구 칸을 밟으면 다시 바깥으로.
3. 맨 안쪽 방에 **보스가 서 있다** (보스 그림을 줄인 필드 스프라이트, 숨 쉬듯 들썩·가까이 가면 "!"). 부딪히면 만남 대사 → (준비 레벨 확인) → 보스전.
4. 이기면 지금처럼 챕터 완료 → 다음 챕터 (던전 안에서 끝나도 됨).

## 원칙
- 길 이어짐 스모크(HeightTests 와 같은 BFS)로 입구 → 보스 앞까지 길이 있는지 맵마다 확인.
- 기존 세이브: 보스 칸에 서 있던 세이브도 바깥 맵에서 시작하니 문제없음. `InDungeon` 은 없으면 false.
