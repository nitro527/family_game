# 이벤트 짜임새 계획 (2026-10-11, 사용자 "단순한 이벤트부터 장기 퀘스트까지 게임을 풍성하게")

## 지금 있는 것
- 찾기 부탁 7개 (챕터마다 하나, 반짝이 셋 찾기 → 특별 장비), 숨겨진 물건 14개, 맵 이벤트 9개(지나가면 대사 한 번), 나무 흔들기·항아리·구멍.
- 모두 "한 번 대사 + 보상" 한 단계짜리. 진행 단계·여러 챕터에 걸친 이야기·사냥/배달 같은 종류가 없다.

## 1. 이벤트 엔진 (데이터로 짜는 장면)
`Resources/Data/stories.json` — 장면 하나 = **언제(Trigger) + 조건(Need) + 차례(Steps)**.
- Trigger: `step`(그 근처를 지나감) · `talk`(마을 사람에게 말 걸기, 평소 대사보다 먼저) · `bump`(물건 살펴보기) · `win`(이 적을 이김) · `enter`(맵에 들어옴)
- Need: 마을 사람 대사 조건 낱말 + `flag:이름` (`!` 반대, `,` 그리고)
- Steps: `talk` 대사 · `give` 아이템/골드/사탕 · `flag` 표시 켜기 · `count` 숫자 올리기 · `sfx` · `sparkle` · `heal` · `battle` 적과 싸우기 · `choice` 예/아니요 갈래 · `cutin`
- Once / 반복, 진행 표시는 세이브의 Opened 에 (`flag_`·`cnt_` — 세이브 버전 그대로)

## 2. 퀘스트 종류 (짧은 것 → 긴 것)
| 종류 | 예 | 단계 |
|---|---|---|
| 맵 반응 | 우물에 동전 던지기, 눈사람 굴리기, 책장 속 쪽지 | 1 |
| 사냥 부탁 | "버섯 젤리 5마리만 혼내 줘" — 이길 때마다 숫자 | 2 (받기 → 다 잡고 알리기) |
| 배달 부탁 | 마을 사람 A 의 물건을 B 에게 | 3 (받기 → 전하기 → 답례) |
| 이어지는 부탁 | 같은 사람이 챕터마다 다음 부탁 | 여러 단계 |
| **장기 퀘스트 1: 가족 앨범** | 챕터마다 경치 좋은 곳에서 가족 사진 (사진 찍는 장면) → 상태 메뉴 "가족 앨범" 에 모임 → 다 모으면 특별 장신구 | 챕터 1~7 |
| **장기 퀘스트 2: 떠돌이 우체부 젤리** | 마을마다 나타나는 우체부 젤리의 편지 배달 (다음 마을로) → 편지마다 짧은 이야기, 마지막에 선물 | 마을 4곳 |

## 3. 화면
- 상태 메뉴 "부탁 수첩": 받은 부탁·진행(3/5)·끝난 것 ✓
- 부탁을 받거나 끝낼 때 짧은 알림 띠

## 순서
1. 이벤트 엔진 + 스모크 테스트 → 2. 사냥·배달 부탁 (챕터마다) → 3. 가족 앨범 → 4. 우체부 젤리 → 5. 부탁 수첩 → 6. 프로브로 몇 개 실제 확인
이야기·이름은 ✏️ 임시 (docs/lore/open_questions.md 에 🙋 로 남김, 게임 글자엔 표시 없음).

## 결과 (2026-10-11)
- **엔진**: `Sim/Stories.cs`(표·조건 낱말·규칙 차례·부탁 수첩) + `View/GameRoot.Stories.cs`(화면 차례·알림 띠·사진 찰칵·수첩·앨범 화면). 대사는 stories.json `Talks`에 두고 대사 표에 합친다.
  - 부르는 곳: 마을 사람 말 걸기(찾기 부탁보다 먼저) · 칸 도착 · 물건 살펴보기 · 전투 승리(무리면 한 마리씩) · 마을 들어감.
  - 조건 낱말 더함: `flag_이름` · `cnt_이름>=N` · `st_이야기` · `photo_사진` · `photos>=N` · `gold>=N` · `opened_세이브표시`.
  - 진행은 세이브 Opened에 (`flag_`·`cnt_이름=N`·`st_`·`photo_`) — 세이브 버전 그대로.
- **내용** (`tools/stories_gen.py`로 만든다): 사냥 7 · 배달 4 · 가족 앨범 7장 → 가족 사진 로켓 · 떠돌이 우체부 젤리(마을 4곳, 새 마을 사람 + 그림) → 우체부 가방 · 우물 소원.
