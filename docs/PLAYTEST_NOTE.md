# 서진이 시험 플레이 메모 (PLAN_NEXT 60)

> 부모님이 옆에서 보면서 적는 종이예요. 인쇄해서 써도 되고, 이 파일에 바로 적어도 돼요.
> 다 적으면 Claude 에게 "시험 플레이 메모 봐 줘"라고 하면, 고칠 것을 백로그로 옮길게요.

## 준비
- 실행: `unity/Build/GirlAdventure.exe` 더블클릭 (2026-10-04 빌드: 챕터 1~5 + 지하세계(서진이 괴물) + 별빛 마을 집 안 + 예티. 타이틀 "챕터 고르기"로 원하는 챕터부터 바로 시작할 수 있어요)
- 세이브 칸 3개 — 서진이 칸을 하나 정해 주세요 (새로 시작하면 그 칸만 지워져요)
- 설정(상태 창 Esc → 설정 / 타이틀의 설정):
  - **지훈 자동 공격**: 지훈이가 명령을 못 고르면 "켬" (지훈 차례에 알아서 싸워요)
  - 글자 속도 / 글자 크기 / 화면 번쩍임 / 음악·효과음 크기
- 조작: 방향키 이동, Z·Enter 고르기, Esc 상태 창·닫기, M 음악 크기
